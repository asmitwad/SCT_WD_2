# ⏱️ Stopwatch App

A modern, responsive stopwatch application built with **React, Vite, and Tailwind CSS**. It features precise time tracking, lap recording, keyboard shortcuts, and dynamic timer colors in a sleek dark interface.

## ✨ Features

- **Start, Pause & Resume** — Control the stopwatch without losing elapsed time.
- **Lap Recording** — Record and display lap times while the stopwatch is running.
- **Clear All Laps** — Clear recorded laps quickly.
- **Reset** — Return the stopwatch and its display to the initial state.
- **Dynamic Timer Colors** — Green while running, red while paused, and white by default.
- **Keyboard Shortcuts** — Control the stopwatch using your keyboard.
- **Responsive Design** — Designed to work across different screen sizes.
- **Animated Background** — Subtle glowing particles and a dark visual theme.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `Space` | Start, pause, or resume |
| `L` | Record a lap |
| `R` | Reset the stopwatch |
| `C` | Clear all laps |

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd stopwatch-app
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173/`.
